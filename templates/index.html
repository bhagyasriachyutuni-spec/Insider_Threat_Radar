AI-Based Insider Threat Detection System

Monitor employee behavior, detect suspicious activity, and prevent security risks using machine learning.

Get Started Admin Access

📌 About the Project

This system detects insider threats by analyzing employee activity patterns such as email usage, attachments, working hours, and behavioral traits. It uses a trained machine learning model to classify users as Normal or Suspicious, along with a calculated risk score.

⚙️ How It Works

1. Input Data

User enters activity metrics

2. ML Model

Random Forest predicts behavior

3. Risk Score

Calculates probability & level

4. Admin Action

Block or monitor user

🚀 Key Features

  • User & Admin authentication system
  • Behavior-based threat prediction
  • Risk score & classification (Low, Medium, High)
  • Admin dashboard with user control
  • Real-time alerts for high-risk users
  • Prediction history tracking

🔄 System Workflow

User Input → ML Prediction → Risk Score → Store in Database → Admin Notification → Action
